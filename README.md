# Event Management App

### Overview

Event management app built during a two-week team challenge. The app allows users to create events, manage bookings, and interact through social features. This project was my first experience working with Expo and React Native. It's built for educational purposes only.


### Main Features

- **Event Management**: Create and edit events with location settings and capacity limits
- **Smart Booking**: Real-time availability tracking with QR code generation
- **Social Features**: User profile and AI-powered username generation
- **Fun Extras**: Built-in dice roller for games and activities

### Known Limitations

- Codebase lacks comments, documentation, and comprehensive review
- Android compatibility has not been fully tested
- AI-powered username generation runs locally only (OpenAI API not yet integrated)
- Design patterns (e.g., atomic design) are not applied in the current structure
